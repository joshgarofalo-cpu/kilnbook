# Kilnbook

Inventory and piece pickups for a paint-your-own pottery studio, built to run on a phone.

- `demo/index.html` is the clickable pitch demo. Open it in a browser. It uses sample data and resets when you refresh.
- `CLAUDE.md` has the full plan, the tech decisions, and what's still open. Claude Code reads it automatically.

To run the demo locally, just open `demo/index.html`, or serve the folder:

```
npx serve demo
```
